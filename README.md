# Eclipse 0.8.0

Interface languages: English · Русский · Deutsch · Suomi · Italiano · Français · Español · Português (Brasil) · 简体中文 · 日本語 · العربية · فارسی

Расширение для подмены языка, локали, часового пояса и геолокации в браузерах Chromium.


[**Поддержать на Boosty**](https://boosty.to/diokyma) · [**Lava.top**](https://app.lava.top/diokyma) · [**ЮMoney**](https://yoomoney.ru/to/4100118568918193)

Eclipse помогает согласовать параметры, по которым сайты определяют язык и регион пользователя. Выберите профиль или задайте язык, часовой пояс и координаты вручную. Расширение универсально и не привязано к отдельной стране.

## Возможности

- Язык и порядок языковых предпочтений в `navigator.language` и `navigator.languages`.
- Заголовок `Accept-Language`, локаль форматирования дат и чисел, часовой пояс.
- Подмена координат по выбору пользователя.
- Каталог региональных профилей, поиск языков и часовых поясов, собственные профили.
- Простой и расширенный режимы, 12 языков интерфейса.
- Диагностика текущей вкладки и проверка внешнего IP по нажатию.
- Зелёный, красный и серый индикаторы состояния.

## Для кого

Для пользователей с несколькими языками, путешественников, пользователей VPN/прокси, которым нужно согласовать настройки браузера с выбранным регионом, а также для изучения и некоммерческой проверки локализации сайтов: языков, дат, чисел, часовых поясов и интерфейсов с геолокацией. Для предотвращения блокирования сервисами, которые могут определять не соответствие между реальным языком и локацией и заявленными.

Расширение не меняет публичный IP, не заменяет VPN и не гарантирует анонимность или доступ к конкретному сервису. Сайты могут учитывать аккаунт, cookies и другие признаки. Для коммерческого использования требуется отдельное разрешение по [лицензии](LICENSE).

## Установка и обновление

Распакуйте архив в постоянную папку. Откройте chrome://extensions (Edge: edge://extensions; Brave: brave://extensions; Opera: opera://extensions; Яндекс: browser://extensions). Включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите папку с manifest.json.

Для сохранения настроек замените содержимое прежней папки новыми файлами, затем нажмите «Обновить» на странице расширений. Загрузка из новой папки создаст отдельную установку. Отключите старое расширение и Cloaq. Закрепите Eclipse в панели.

## Простой режим

Включение, выбор профиля региона, язык для сайтов, сохранение, перезагрузка и проверка. Выбранный профиль задаёт язык, часовой пояс и координаты. Последующий выбор языка сохраняет часовой пояс и координаты. Кнопка питания сразу сохраняет и применяет параметры. При включении остаётся нажатой; повторное нажатие выключает подмену. Рядом отображаются индикатор и состояние текущей вкладки. Если меняете параметры при уже включённой подмене, нажмите «Сохранить». Перезагрузка страницы для применения не требуется.

В каталоге 851 локаль ICU, варианты отбираются по поддержке браузера. В среде проверки: 843 языковых варианта, 827 профилей с регионом и координатами. Это региональные варианты, а не столько разных языков. У вариантов без определимого региона (например, надрегионального) готового геопрофиля нет: задайте географию вручную.

Геопрофили используют опорный город первого часового пояса региона из zone.tab, а не фактическое местоположение пользователя и не обязательно столицу. Город/часовой пояс показан в названии. В странах с несколькими поясами можно выбрать другой в расширенных настройках.

## Расширенный режим

Сворачиваемые разделы: языки и порядок предпочтений, часовые пояса с поиском, координаты, собственные профили, информация о работе. Режим и раскрытие разделов запоминаются.

Собственный профиль: задайте параметры, введите название, нажмите «Сохранить профиль». Это создаёт шаблон; для применения нажмите общую кнопку «Сохранить». Удаление возможно только для собственных профилей.

Язык интерфейса выбирается отдельно в шапке: системный, русский, английский, немецкий, финский, итальянский, французский, испанский, португальский (Бразилия), китайский (упрощённый), японский, арабский и фарси. Арабский и фарси используют направление справа налево. При первом запуске используется язык интерфейса браузера, затем navigator.language. Если перевода нет, выбирается английский. Обычное расширение не может независимо читать реальный язык Windows, если язык браузера от него отличается. Смена языка интерфейса не меняет подмену сайтов; перед сменой сохраните сделанные настройки. Технические ошибки браузера/отладчика могут показываться в исходном виде.

## Значок и состояние

Монохромный значок с двумя перекрывающимися кругами и звёздочкой на прозрачном фоне. Зелёная точка #2b973c и красная #972b2b без обводки показывают состояние. Зелёная точка: настройки успешно применены к вкладке; красная: ошибка применения или обнаруженное расхождение при проверке. Серая: выключено или страница недоступна. Текст ON удалён. Цвет отражает состояние подмены, а не работу VPN или доступность внешнего сервиса IP.

Зелёный цвет не гарантирует прохождение всех fingerprint-тестов. Наличие параметров в основном контексте проверяется кнопкой; ранее сохранённые в переменных сайта данные не переписываются задним числом.

## Проверка вкладки и IP

Одна кнопка параллельно проверяет язык/локаль/часовой пояс основного контекста вкладки и делает HTTPS-запрос к https://ipwho.is/. Внешний сервис видит исходящий публичный IP расширения, но ему не передаются URL вкладки, её содержимое, cookies или настройки профиля. Запрос без credentials, referrer и кэша, с таймаутом 8 секунд. Фонового отслеживания IP нет.

Показываются IP, приблизительная страна/город и пояс. Местоположение по IP приблизительное. При PAC, split tunneling, прокси только для части сайтов или разных маршрутах IP расширения может отличаться от IP вкладки. Это не доказательство сетевого адреса, видимого любому конкретному сайту. Недоступность IP API показывается отдельно и не меняет статус подмены. Встроенная диагностика не проверяет фактический Accept-Language на сервере, workers, DNS, WebRTC или геолокационное разрешение.

Документация IP: https://ipwhois.io/documentation

## Ограничения

Требуются Chrome Debugger API, Manifest V3, storage.session, scripting, declarativeNetRequest; основной ориентир — Chromium 125+. Поддержка API Edge подтверждена документацией, Brave/Opera/Яндекс используют общую архитектуру Chromium, но запуск этой сборки в этих браузерах ещё нужно проверить. Firefox/Safari этим пакетом не поддерживаются. Мобильные браузеры не входят в целевые платформы.

Chrome показывает уведомление об отладке; открытие DevTools или другой отладчик может прервать подмену. Первый запрос вкладки может уйти до подключения. Отдельные процессы iframe и workers не подключаются как отдельные targets. IP, DNS, WebRTC, шрифты, cookies и настройки аккаунта не подменяются. Геолокация требует разрешения сайта.

node tests/native.cjs
node tests/languages.cjs
node tests/zones.cjs
node tests/ui.cjs
node tests/tab-action.cjs

Проверены жизненный цикл подмены с моделью Chrome API, поиск, локали, профили, переводы, переключение режимов, сохранение профилей, обработка успешного/недоступного IP-сервиса. Реального установленного браузера в среде сборки нет: визуальная и сетевая проверка на устройстве пользователя ещё нужна. Подготовлены размеры иконки для панели и варианты с точками состояния.
